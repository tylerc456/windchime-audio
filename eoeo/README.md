# Eoeo

Concentric-ring sample looper — a mobile-first mockup.

Open `index.html` in a browser (or serve this folder) to try it. Rings are loop lengths in beats (center = 1 beat, each ring out doubles). Tap a ring to record a take, drag a waveform to roll it, drag it to another ring for Tile / Move / Copy. New Song opens a donut split into sections with Pad / Mic recording.
